# Rust Port

::: warning Status: in progress, not released
A Rust implementation of Codigest is being worked on. **Nothing described on this site is available in Rust.** The Python package on PyPI is the only released implementation, and every page here documents it.
:::

## What exists today

- The released tool is the Python package: `uv tool install codigest`. See [Installation](/installation).
- The Rust implementation is still being written. It has no release, no installer and no stable interface.
- No Rust build is published. Do not assume that any command, option or output format on this site behaves the same way in it.

## What to expect from this page

When there is something to try, this page will say what works, how to install it, and what differs from the Python version. Until then, use the Python package.

## Where to follow it

The repository is [NaNIsaac/codigest](https://github.com/NaNIsaac/codigest). No plan document is published in it yet; when one is, it will be linked from here.
