# Rust 포팅

::: warning 상태: 진행 중, 아직 배포 전
Codigest의 Rust 구현을 만들고 있습니다. **이 사이트에서 설명하는 어떤 기능도 Rust 버전에서는 아직 쓸 수 없습니다.** 지금 배포된 구현은 PyPI의 Python 패키지뿐이고, 이 사이트의 모든 페이지는 그것을 설명합니다.
:::

## 지금 있는 것

- 배포된 도구는 Python 패키지입니다: `uv tool install codigest`. [설치](/ko/installation)를 참고하세요.
- Rust 구현은 아직 만드는 중입니다. 배포본도, 설치 방법도, 안정된 인터페이스도 없습니다.
- 배포된 Rust 빌드는 없습니다. 이 사이트의 어떤 명령, 옵션, 출력 형식도 Rust 버전에서 같게 동작한다고 가정하지 마세요.

## 이 페이지에서 앞으로 다룰 것

써 볼 수 있는 것이 생기면, 이 페이지에서 무엇이 동작하는지, 어떻게 설치하는지, Python 버전과 무엇이 다른지를 알려 드리겠습니다. 그때까지는 Python 패키지를 쓰세요.
